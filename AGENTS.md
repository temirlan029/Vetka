# Проект: Vetka — Discord-бот для приватных веток

## Репозиторий
- GitHub: https://github.com/temirlan029/Vetka.git
- Ветка: main
- Хостинг: Railway (автодеплой из GitHub)

## Стек
- Python 3.12
- discord.py >= 2.3.0
- python-dotenv >= 1.0.0

## Структура
- `bot.py` — основной код бота
- `.env` — переменные окружения (см. ниже)
- `requirements.txt` — зависимости
- `Procfile` — для Railway (`worker: python bot.py`)
- `runtime.txt` — версия Python
- `AGENTS.md` — документация проекта

## Переменные окружения (.env и Railway)
- `BOT_TOKEN` — токен Discord-бота
- `ROLE_IDS` — ID ролей через запятую (участники с этими ролями добавляются в ветки)
- `OWNER_ID` — ID владельца (846507833599983647), бот пишет ему в ЛС при проблемах
- `GUILD_ID` — ID сервера (1498790092104401009), бот работает только на этом сервере

## Функциональность
- Команда `/setup` — отправляет embed с кнопкой "Создать приватную ветку"
- По нажатию кнопки создаётся приватная ветка `ветка-[имя]`
- В ветку автоматически добавляются участники с ролями из ROLE_IDS
- Бот привязан к одному серверу (GUILD_ID), slash-команды синхронизируются только туда

## Защита от пропадания веток (3 слоя)
1. `auto_archive_duration=10080` — максимальное время до архивации (7 дней)
2. `on_thread_update` — мгновенная реакция: если ветка заархивировалась, бот сразу разархивирует
3. Фоновая задача `tasks.loop(minutes=5)` — каждые 5 минут проверяет все архивированные ветки
4. При запуске бота (`on_ready`) — сразу проверяет и восстанавливает ветки, пропущенные пока бот был оффлайн

## Уведомления владельцу
- При восстановлении заархивированной ветки бот пишет владельцу в ЛС:
  `"⚠️ Ветка **ветка-имя** в #канал пропала (заархивировалась), но я её восстановил."`
