# Проект: Vetka — Discord-бот для приватных веток

## Репозиторий
- GitHub: https://github.com/temirlan029/Vetka.git
- Ветка: main
- Хостинг: Railway (автодеплой из GitHub)

## Стек
- Python 3.12
- discord.py >= 2.3.0
- python-dotenv >= 1.0.0

## Структура
- `bot.py` — основной код бота
- `.env` — токен бота (BOT_TOKEN) и ID ролей (ROLE_IDS через запятую)
- `requirements.txt` — зависимости
- `Procfile` — для Railway (`worker: python bot.py`)
- `runtime.txt` — версия Python

## Функциональность
- Команда `/setup` — отправляет embed с кнопкой "Создать приватную ветку"
- По нажатию кнопки создаётся приватная ветка `ветка-[имя]`
- В ветку автоматически добавляются участники с ролями из ROLE_IDS
- Ветки не архивируются: `auto_archive_duration=10080` + `on_thread_update` + фоновая задача каждые 5 минут + проверка при старте

## История изменений
- **2026-05-02**: Исправлена проблема с пропаданием (архивацией) веток:
  - Добавлен `auto_archive_duration=10080` (макс. 7 дней) при создании ветки
  - Добавлен `on_thread_update` — автоматическое разархивирование веток, созданных ботом

- **2026-05-03**: Ветки всё ещё пропадали — добавлена надёжная защита:
  - Фоновая задача `tasks.loop(minutes=5)` — каждые 5 минут проверяет и разархивирует ветки
  - При запуске бота (`on_ready`) — сразу проверяет все архивированные ветки
  - Это покрывает случаи, когда бот был оффлайн (деплой/перезапуск) и пропустил событие архивации

## Деплой
- Пуш в `main` на GitHub -> Railway автоматически подхватывает и деплоит
