Напиши код для Discord-бота на [Python (discord.py) / JavaScript (discord.js)], который создает приватные ветки через кнопку.

Логика работы:

Должна быть команда (например, /setup), которая отправляет сообщение с кнопкой «Создать приватную ветку».

Когда пользователь нажимает на кнопку:

Бот создает Private Thread (приватную ветку) в этом канале.

Название ветки должно быть: ветка-[имя пользователя].

Доступ: Бот должен автоматически тегнуть (упомянуть) в этой ветке конкретную роль по её ID (например, роль модераторов или поддержки), чтобы они её увидели.

Автор ветки тоже должен иметь к ней доступ.

В самой ветке бот должен отправить сообщение: «Ветка создана! Участники с ролью [Название роли] и @пользователь, пишите здесь».

Технические детали:

Используй View и Button для создания интерфейса.

Ветка должна быть именно типа Private, чтобы её не видели остальные участники сервера.

ID роли, которую нужно тегать, вынеси в отдельную переменную в начале кода.
